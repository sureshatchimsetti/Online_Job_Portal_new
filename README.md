#  Online Job Portal

A dynamic and responsive **Spring Boot-based web application** that enables job seekers, employers, and admins to interact within a unified platform.

---

##  Features

- 👤 **User Roles**: Admin, Employer, Job Seeker
- 🔐 **Authentication & Authorization**: Secure login and signup for all roles
- 🔎 **Job Search**: Filter jobs by title, location, company, and category
- 📩 **Job Application**: Apply, withdraw, and track job status
- 📝 **Job Posting**: Employers can post, edit, and delete job listings
- 📊 **Admin Dashboard**: Manage users, jobs, and site-wide settings

---

##  Technologies Used

- **Backend**: Java, Spring Boot, Spring Security, Spring Data JPA
- **Frontend**: HTML, CSS, Bootstrap, Thymeleaf
- **Database**: MySQL
- **Build Tool**: Maven
- **Version Control**: Git & GitHub
